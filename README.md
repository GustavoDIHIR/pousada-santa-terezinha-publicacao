# Pousada Santa Terezinha · Publicação do protótipo

Artefato estático gerado a partir de https://github.com/GustavoDIHIR/pousada-santa-terezinha .

Dados de demonstração ficam somente nesta aba do navegador. Não use dados pessoais reais. Não há autenticação, agenda compartilhada, pagamentos ou e-mails reais nesta publicação.

Fonte, servidor, testes e documentação ficam no repositório de código. Atualize esta publicação com `npm run build:prototype` naquele repositório.
